# Rules for Codex

## Structure
- Frontend: /frontEnd/EnglishPlateforme
- Backend:
  - Eureka: /backEnd/eureka
  - Gateway: /backEnd/Gateway
  - Microservices: /backEnd/microservices

## Editing Rules
- Only edit when I explicitly ask
- Keep changes small and simple
- Do not modify unrelated files

## Safety
- Do not hardcode URLs, ports, or credentials
- Reuse existing config and patterns

## Before Editing
- List files to change
- Explain what will be done briefly

## After Editing
- Create or update a file at root: CHANGE_LOG.md
- In CHANGE_LOG.md include:
  - files modified
  - what was changed (simple explanation)
  - why the change was made

## Behavior
- Prefer simple solutions
- Do not over-engineer
- If unsure, say "I am not sure"
