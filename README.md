Fluency is a full-stack web application developed as part of a 4th-year software engineering project (PiDev) at a Tunisian engineering school. The platform is designed to manage various academic and associative activities, including courses, candidatures, evaluations, payments, and a community forum. The application is built by a team of 5 students, each responsible for a specific management module.
##🗨️ Forum Management (Nidhal F.)

Browse and manage forum categories Create, edit, and delete discussion topics Reply to topics and manage responses Email notifications via SMTP — topic authors receive an email when someone replies to their topic Multi-criteria search — filter topics by title and date in real time (AJAX) Admin notifications for every forum action (topic created, deleted) Delete confirmation modals for safe data management
