🎓 Fluency — English School Platform
📋 Overview
Fluency is a full-stack web application developed as part of a 4th year Software Engineering project (PiDev) at ESPRIT School of Engineering.
The platform manages various academic and associative activities including courses, candidatures, evaluations, payments, association management and a community forum.
The application is built by a team of 5 students, each responsible for a specific management module, following a Microservices Architecture with Eureka Service Discovery and API Gateway.
✨ Features
🗨️ Forum Management 

Browse and manage forum categories with topic count display
Create, edit, and delete discussion topics with author email
Add and manage replies on topics
Automatic bad word detection — replies with inappropriate words are blocked
Report system — users can report replies (Inappropriate / Spam / Harassment / Other)
Email notifications via SMTP — topic authors are notified when someone replies
Admin notifications — admin receives email on every forum action
Multi-criteria search — filter topics by title and date in real time (AJAX)
Delete confirmation modals for safe data management

📚 Course Management

Manage and browse available courses
Course categories and content organization
Enrollment and tracking system

🎓 Candidature Management

Handle student applications and candidatures
Application status tracking
Document management

📋 Evaluation Management

Manage assessments and evaluations
Grade tracking and reporting
Student performance analytics

💳 Payment Management

Handle payment processing and tracking
Invoice generation
Payment history

🤝 Association Management

Manage associative activities and members
Event planning and tracking
Member roles and permissions
